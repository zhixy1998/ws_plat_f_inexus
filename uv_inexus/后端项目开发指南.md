## 一、项目概述

### 1.1 这是什么系统？

UV-iNexus 是**普析通用仪器有限责任公司**的紫外可见分光光度计工作站软件后端服务。

```
仪器硬件（光谱仪） ←Netty TCP/UDP→ 后端服务(本项目) ←HTTP/WebSocket→ 前端页面
```

后端负责：
- 接收前端指令，控制仪器硬件（设波长、测量、校零等）
- 从仪器接收测量数据，计算处理，存入数据库
- 管理用户/权限、方法、任务、样品等业务数据
- 调用 Python 算法服务做曲线拟合、寻峰等数学计算
- 通过 WebSocket 实时推送测量进度和数据给前端

### 1.2 技术栈

| 类别 | 技术 | 版本 |
|---|---|---|
| 语言 | Java | 1.8 |
| 框架 | Spring Boot | 2.6.13 |
| ORM | MyBatis-Plus | 3.5.6 |
| 数据库 | MySQL | 多数据源 |
| 缓存 | Ehcache 3 (JSR-107) | 3.10.8 |
| 通信 | Netty（仪器通信）+ WebSocket（前端推送） | 4.1.113 |
| JSON | FastJSON2 + Jackson | - |
| Excel | Apache POI | - |
| 算法服务 | Python（HTTP调用） | 独立部署 |

## 二、环境搭建

### 2.1 前置依赖

1. **JDK 1.8**
2. **MySQL 5.7+**（需创建3个数据库，见下文）
3. **Maven 3.6+**
4. **Python 算法服务**（独立部署，提供曲线拟合等接口）
5. **仪器模拟器或真实硬件**（开发阶段可用模拟器）

### 2.2 数据库配置

系统使用**动态多数据源**（`dynamic-datasource`），共3个库：

| 数据源名 | 数据库 | 用途 |
|---|---|---|
| `guide`（默认） | `t800_uv_inexus` | 向导模式：光度测量/定量测定/光谱扫描/时间扫描 |
| `concise` | `t800_uv_inexus_concise` | 经典模式：简洁版测量 |
| `factory_inspection` | `t800_uv_inexus_factory_inspection` | 检定校准：出厂检定/校准任务 |

配置文件：[application-dev.yml](src/main/resources/application-dev.yml)

```yaml
spring:
  datasource:
    dynamic:
      primary: guide  # 默认数据源
      datasource:
        guide:
          url: jdbc:mysql://localhost:3306/t800_uv_inexus
          ...
        concise:
          url: jdbc:mysql://localhost:3306/t800_uv_inexus_concise
          ...
        factory_inspection:
          url: jdbc:mysql://localhost:3306/t800_uv_inexus_factory_inspection
          ...
```

数据库初始化SQL位于：`Apply_database_updates/数据库初始化文件/` 目录下，按版本选择对应的初始化脚本。

### 2.3 启动

```bash
# 开发环境（默认）
mvn spring-boot:run

# 或打包后运行
mvn clean package -DskipTests
java -jar target/uv_inexus-1.0-SNAPSHOT.jar
```

配置切换：修改 [application.yml](src/main/resources/application.yml) 中 `spring.profiles.active` 为 `dev` 或 `prod`。

### 2.4 Python 算法服务

```yaml
# application-dev.yml
python-code:
  baseUrl: http://192.168.61.82:8002/
```

提供接口：最小二乘拟合、浓度计算、寻峰、基线校正等。Java 端通过 [RestUtil.java](src/main/java/com/persee/workstation/uv_inexus/util/pythonUtil/RestUtil.java) 调用。

### 4.2 向导模式（guide 库）

**代码位置**：`controller/guide/`、`service/guide/`、`websocket/measure/`

向导模式是面向普通实验员的日常测量模式，提供分步向导式的操作界面。

| 定量测定 | [RationController](src/main/java/com/persee/workstation/uv_inexus/controller/guide/measurementController/RationController.java) | RationServiceImpl | [RationMeasureNewWebSocket](src/main/java/com/persee/workstation/uv_inexus/websocket/measure/RationMeasureNewWebSocket.java) |
| 光谱扫描 | [SpectrumController](src/main/java/com/persee/workstation/uv_inexus/controller/guide/measurementController/SpectrumController.java) | SpectrumServiceImpl | [SpectrumNewWebSocket](src/main/java/com/persee/workstation/uv_inexus/websocket/measure/SpectrumNewWebSocket.java) |

经典模式是向导模式的简洁版，界面更紧凑，操作更快捷。业务逻辑与向导模式高度相似，但独立维护了一套数据表。

**核心Controller**：

### 4.4 检定校准（factory_inspection 库）

**代码位置**：`controller/factory_inspection/`、`service/factory_inspection/`、`websocket/factory_inspection/`

这是仪器出厂前的检定/校准模块。与测量模式完全不同，它基于 **Excel 模板**驱动：
- 每个检定项目对应一个 Excel 模板
- 系统通过 POI 加载 Excel，实时编辑单元格
- WebSocket 推送变更给前端
- 测量数据直接写入 Excel 对应位置

**核心文件**：
- [ExcelWebSocketHandler.java](src/main/java/com/persee/workstation/uv_inexus/websocket/factory_inspection/ExcelWebSocketHandler.java) — 核心处理器（文件较大，约5000+行）
- [TaskManagementController.java](src/main/java/com/persee/workstation/uv_inexus/controller/factory_inspection/TaskManagementController.java) — 任务管理
- [TemplateController.java](src/main/java/com/persee/workstation/uv_inexus/controller/factory_inspection/TemplateController.java) — 模板管理

## 六、核心流程：以定量测定为例

### 6.1 测量流程

```
用户在前端操作                     后端处理                        数据库/仪器
─────────────                    ──────────                     ──────────
1.选择方法参数          →  Controller.checkParam()
                         →  Service.updateMethodParam()     →  更新 t_measure_method

2.新建任务              →  Controller.newDraft()            →  插入 t_measure_task

3.添加标准/未知样品     →  Controller.addOrDeleteSample()   →  插入/删除 t_measure_sample
                                                            →  更新 task.sample_key JSON

4.校零                  →  Controller.zero()               →  仪器测量空白
                                                            →  保存 zero_param

5.下发参数到仪器        →  Controller.setUpParametersPort() →  Netty发送命令给仪器

6.点击"测量"            →  WebSocket.startMeasure()
                         →  向仪器发测量命令
                         →  接收仪器返回数据                ←  仪器返回原始光谱数据
                         →  countAbsValue() 计算吸光度
                         →  fittingCurve() 拟合标准曲线     →  调用Python算法
                         →  saveSampleMeasureData()         →  插入 t_measure_data
                         →  valueCalculate() 计算未知样浓度
                         →  WebSocket推送结果给前端          →  前端实时更新

7.查看/导出             →  Controller.queryCurveInfo()      →  查询曲线数据
                         →  Controller.downloadDoc()        →  生成报告
```

### 6.2 关键概念

- **方法(Method)**：一套测量参数配置（波长、曲线类型、修约规则等），可保存复用
- **任务(Task)**：一次具体的实验测量，关联一个方法
- **样品(Sample)**：分三种——标准样(stand，已知浓度)、空白样(empty，校零用)、未知样(unknown，待测)
- **标准曲线**：用标准样的(浓度, Abs)数据拟合出的数学方程，用于计算未知样浓度
- **拟合参数(fittingParam)**：标准曲线的系数、方程、R²等，以JSON存在任务的 `fitting_param` 字段

## 八、数据库变更管理

SQL变更文件存放在 `Apply_database_updates/` 目录：

```
Apply_database_updates/
├── 数据库初始化文件/                          # 全量初始化脚本（按版本）
│   ├── （实验测试）版本初始化数据库/
│   └── （检定校准02-06）版本初始化数据库/
├── 数据库结构更新写入文件(当前版本：1.0.0)/   # 增量变更脚本（按日期）
│   ├── 2025-11-13__1.0.0/
│   ├── 2026-01-16_1.0.0/
│   └── ...（每次发版的SQL变更）
└── 说明文件/
```

**约定**：每次涉及表结构变更，在 `数据库结构更新写入文件` 下按 `YYYY-MM-DD_版本号` 建目录，放入对应表的SQL文件。

## 九、常见问题

### 9.1 新人接手第一步做什么？

1. 搭建本地数据库（执行初始化脚本）
2. 修改 `application-dev.yml` 中的数据库连接和Python服务地址
3. 启动项目，访问 `http://localhost:8081` 确认服务正常
4. 阅读本文档第四、五、六章建立全局认知
5. 选择一个具体模块（如定量测定），从前端页面操作 → 对应Controller → Service → WebSocket 逐层跟踪

### 9.2 向导模式和经典模式有什么区别？

| 对比 | 向导模式 | 经典模式 |
|---|---|---|
| 界面 | 分步向导，每步独立页面 | 紧凑三栏布局，一页完成 |
| 代码包 | controller/guide/ | controller/concise/ |
| 业务逻辑 | 基本相同 | 基本相同 |
| 定量测定详细文档 | 参见 docs/经典模式-定量测定-后端代码导航.md | 同左 |

### 9.3 仪器通信出问题怎么排查？

1. 检查 `application-dev.yml` 中 `device.default` 的IP和端口配置
2. 查看日志中 Netty/UDP 相关的连接和收发日志
3. 确认仪器模拟器或真实硬件是否在线
4. 检查 [DeviceConnectionManager](src/main/java/com/persee/workstation/uv_inexus/util/deviceUtil/DeviceConnectionManager.java) 的连接状态

### 9.4 WebSocket 连接地址

前端通过 WebSocket 与后端建立长连接，用于实时接收测量数据推送：

- 测量数据推送：各测量类型的 WebSocket Handler（如 `ConciseRationMeasureNewWebSocket`）
- 检定校准推送：`ExcelWebSocketHandler`
- 配置参见 [WebSocketConfig.java](src/main/java/com/persee/workstation/uv_inexus/config/WebSocketConfig.java)
